CAS II · Computational Algorithmic Statistics

Orbits as Models

Kolmogorov’s Structure Function under Symmetry

Romie Banerjee · October 2026

Abstract

In algorithmic statistics a string \(x\) is explained by a finite set containing it, and Kolmogorov’s structure function records the smallest such model at each level of complexity. The strong models of Vereshchagin, those computable from the data by a total algorithm, are essentially the cells of simple partitions. So a partition of \(\{0,1\}^n\) can be read as a hypothesis, and the cell containing \(x\) as the model it assigns. We develop algorithmic statistics over symmetric partitions, the orbit partitions of groups acting on strings.

The Galois connection between subgroups and partitions assigns to each ambient group \(G\) a lattice \(\mathrm{Par}_G\) of symmetric partitions. Each has a canonical certificate whose cost equals that of the partition, and hypotheses can be combined by joins and meets. A set is a cell of some symmetric partition exactly when its setwise stabiliser in \(G\) acts transitively on it, and naming such a cell already names a canonical hypothesis. So the resulting structure function \(h^G_x\) is Kolmogorov’s structure function restricted to these \(G\)-homogeneous sets. It and the symmetric sophistication \(\mathrm{soph}^G(x)\) measure which part of the regularity of \(x\) is symmetric.

For \(G=\mathrm{Sym}(\{0,1\}^n)\) every partition is symmetric. Cells then recover all Kolmogorov models, and cells of cheap partitions recover exactly the strong models, so normal and strange strings are characterised by symmetry. For \(G=\mathrm{GL}(n,2)\) the homogeneous sets are exactly the linearly homogeneous sets, those whose XOR dependencies look the same from every point. For every nonzero \(x\), \(h^{\mathrm{GL}}_x\) lies in a band between \(C(x)-\alpha\) and \(n-\alpha\), and both edges are attained. In particular, there are stochastic normal strings whose simple structure is entirely invisible to linear symmetry: \(\mathrm{soph}(x)\approx0\) but \(\mathrm{soph}^{\mathrm{GL}}(x)\approx C(x)\).

Finally, we coordinatise the space of permutation groups. Each group is an element of a Burnside ring (its type) together with a permutation (its placement), and restriction moves refine partitions cell by cell via the Mackey formula. In these coordinates the collapse for \(\mathrm{Sym}\) is essentially a statement about placement, a linear hypothesis is determined by its type up to \(n^2\) bits, and the maximal gap theorem shows that any space of symmetry hypotheses small enough to search is small enough to miss simple structure. These coordinates and limits set up the learned search over orbit models developed in later papers of the series.

1 Introduction

1.1 Models, strong models and partitions

Kolmogorov proposed to explain a string \(x\) by a finite set \(S\ni x\), a model, and to measure the explanation by the two-part code \(C(x)\lesssim C(S)+\log|S|\): first the model, then the position of \(x\) in it, which is treated as noise [4, 2, 13, 12]. The structure function \(h_x(\alpha)\) records the smallest model affordable at complexity \(\alpha\), and a model is a sufficient statistic when the two parts together cost no more than \(C(x)\).

Arbitrary finite sets are too generous as models. The universal models of Gács, Tromp and Vitányi [2] can be sufficient, yet they encode the number of strings of bounded complexity, so they cannot be found from the data. Vereshchagin [11] therefore singled out the strong models: those computable from \(x\) by a total algorithm. A total algorithm \(x'\mapsto A(x')\) assigns a model to every string, and Milovanov [7] observed that this makes strong models essentially the cells of simple partitions of \(\{0,1\}^n\). So beneath algorithmic statistics lies a theory of partitions. A partition \(p\) is a hypothesis: a classification of all strings into classes of strings the hypothesis cannot tell apart. The model for \(x\) is its cell, and the description becomes \[\tag{1.1} C(x)\ \lesssim\ \underbrace{C(p)}_{\text{hypothesis}} \ +\ \underbrace{C(B\mid p)}_{\text{which cell}} \ +\ \underbrace{\log|B|}_{\text{noise}}, \qquad x\in B\in p .\]

1.2 Symmetric partitions

Which partitions are structured hypotheses? The most natural source of classifications in mathematics and physics is symmetry: two strings are indistinguishable if some transformation from a group maps one to the other. The hypothesis is then the orbit partition of a group \(U\) acting on strings, and the size of the cell of \(x\) is governed by its symmetry. By the orbit–stabiliser theorem, \[\log|U\cdot x|=\log|U|-\log|\mathrm{stab}_U(x)|=-\log\Pr_{u\in U}[ux=x],\] so strings with large stabilisers lie in small cells and receive short descriptions in (1.1). This is the precise sense in which symmetric objects are simple: a symmetry hypothesis explains \(x\) well when it is cheap and \(x\) is fixed by a large part of it.

Different groups can have the same orbits and then make the same hypothesis, so the group is best seen as a certificate that a partition arises from symmetry. The classical Galois connection between subgroups and partitions [3] makes this precise. For an ambient group \(G\) acting on strings it singles out a lattice \(\mathrm{Par}_G\) of symmetric partitions. Each symmetric partition has a canonical certificate, the largest subgroup with those orbits, which costs exactly as much as the partition. Hypotheses can be combined by joins and meets, and conjugation acts as relabelling. The theory of this paper is algorithmic statistics restricted to cells of symmetric partitions. These cells have an intrinsic description: a set is a cell exactly when its setwise stabiliser acts transitively on it, and the cell then carries a canonical hypothesis at no extra cost (Proposition 3.5). So the theory is that of a restricted model class in the sense of Vereshchagin and Vitányi [14].

The choice of ambient group matters. For \(G=\mathrm{Sym}(\{0,1\}^n)\) every partition is symmetric, and symmetry adds nothing to the theory of strong models. Its canonical certificates are Young subgroups, whose type records only the sizes of the cells, so for complex models the information sits in how the symmetry is placed (Proposition 9.4). At the other extreme, the orbit partition of the stabiliser of \(x\) in a large group has \(\{x\}\) as a cell: a lossless description that costs \(C(x)\). The informative cases lie in between and arise from structured ambient groups, above all the group \(\mathrm{GL}(n,2)\) of linear symmetries of \(\mathbb{F}_2^n\).

1.3 The question and the results

\(C(x)\) can always be recovered from a symmetric partition at full price, so the question is not whether but how: which part of the regularity of \(x\) is captured by cells of symmetric partitions, and at what cost? We measure this by the structure function \(h^G_x\) over \(\mathrm{Par}_G\), and summarise it by the symmetric sophistication \(\mathrm{soph}^G(x)\), the least cost at which a cell of a symmetric partition is a sufficient statistic.

  1. Framework (Sections 3–4). The Galois connection between subgroups and partitions: symmetric partitions, their canonical certificates and costs, the characterisation of cells as homogeneous sets, an algebra of joins and meets, and relabelling. Partition structure functions reduce to structure functions over homogeneous sets, and come with a dictionary between the group and partition formulations.

  2. All permutations (Section 5). Every partition is symmetric. Cells of symmetric partitions recover all Kolmogorov models, and cells of cheap ones recover exactly the strong models. The canonical certificates are Young subgroups whose type records only cell sizes; for complex models all but \(O(2^{n/2})\) bits of their information sit in the placement.

  3. Linear symmetry (Section 6). The cells of \(\mathrm{Par}_{\mathrm{GL}}\) are the linearly homogeneous sets, a combinatorial class defined by XOR dependencies, but whole symmetric partitions are rigid. Affine subspaces are cells of cheap symmetric partitions.

  4. A band and its extremes (Sections 7–8). For nonzero \(x\), \(C(x)-\alpha\le h^{\mathrm{GL}}_x(\alpha)\le n-\alpha\), both edges are attained, and there are stochastic normal strings with \(\mathrm{soph}(x)\approx0\) but \(\mathrm{soph}^{\mathrm{GL}}(x)\approx C(x)\): their regularity is simple and computable, yet no linear symmetry captures any of it. Figure 5 places all the structure functions of the paper in one picture.

  5. Coordinates and search (Section 9). Every permutation group is a Burnside ring element (its type) together with a permutation (its placement), which gives coordinates on the spaces of permutation groups and symmetric partitions, and moves for navigating them. In \(S_X\) the information of a hypothesis sits almost entirely in its placement, whereas a linear hypothesis is determined by its type up to \(n^2\) bits. The maximal gap theorem limits what any search in these coordinates can achieve: coordinates small enough to search are small enough to miss simple structure.

Figures 2, 3, 6 and 7 illustrate cells, orbits, types and placements on the \(3\)- and \(4\)-cubes, and Section 10 collects open problems.

1.4 Place in the series and outlook

This is the second paper in a series on computational algorithmic statistics. CAS I [1] treats symmetries as a lossless description language: a string is singled out as the unique fixed point of a symmetry, and for fix-retractable groups the resulting prior satisfies a coding theorem. That result is the algorithmic-probability form of a theorem of Trejo, Kreinovich and Longpré [10], who showed that the corresponding complexity equals Kolmogorov complexity up to an additive constant. In the full group of computable bijections, however, every string has the same symmetries, so this reading measures how cheaply \(x\) can be singled out, not how symmetric \(x\) is. The present paper takes the complementary, lossy view: symmetries group strings into orbits, and an orbit is a model whose size is governed by the stabiliser.

Later papers in the series will develop learned search, in particular reinforcement learning, over orbit models. The theory here is meant to make that search well posed. The coordinates of Section 9 give the state and action spaces: a hypothesis is a type together with a placement, and the moves are relabelling, restriction with its Mackey splitting of cells, and meets with other cheap hypotheses. The symmetric structure function gives the objective, through the deficiency \(C(p,B)+\log|B|-C(x)\) of the model found, with \(C(x)\) estimated by a compressor. The maximal gap theorem says what failure means: a search that finds no good orbit model has shown that \(x\) has little symmetric structure, not that it is random (Section 9.3). The recommendations at the end of Section 9.3, to search types first and to refine by restriction and meets, are a first prior for such policies.

2 Preliminaries

2.1 Structure functions and sophistication

\(C\) is plain Kolmogorov complexity and \(\mathit{CT}(y\mid x)\) the total conditional complexity: the length of a shortest program that maps \(x\) to \(y\) and halts on every input. Strings have length \(n\). Statements said to hold “up to \(O(\log n)\)” hold up to additive \(O(\log n)\) terms in all coordinates; \(c\) denotes a sufficiently large constant.

Definition 2.1. The structure function of \(x\in\{0,1\}^n\) is \(h_x(\alpha)=\min\{\log|S| : x\in S\subseteq\{0,1\}^n,\ C(S)\le\alpha\}\) for \(\alpha\ge c\log n\). A model is sufficient if \(C(S)+\log|S|\le C(x)+c\log n\), and the sophistication \(\mathrm{soph}(x)=\min\{\alpha : h_x(\alpha)+\alpha\le C(x)+c\log n\}\) is the complexity of a minimal sufficient statistic [5, 2, 13]. The string is stochastic if \(\mathrm{soph}(x)=O(\log n)\), and antistochastic if \(h_x(\alpha)\approx n-\alpha\) for all \(\alpha<C(x)\) [6].

Lemma 2.2 ([13, 9]). For \(x\in\{0,1\}^n\) with \(C(x)=\kappa\), up to \(O(\log n)\): (i) \(h_x(\alpha)\ge\kappa-\alpha\); (ii) \(h_x(c\log n)\le n\) and \(h_x(\kappa)=0\); (iii) (halving law) \(h_x(\alpha)+\alpha\) is non-increasing. Conversely [13], every simple function with (i)–(iii) is the structure function of some \(x\) up to \(O(\log n)\); such functions are called admissible.

Figure 1 shows a typical structure function. The curve starts near \(n\), where the only affordable model is essentially \(\{0,1\}^n\), and reaches \(0\) at \(\alpha\approx C(x)\), where \(\{x\}\) is affordable. It never lies below the sufficiency line \(C(x)-\alpha\) (Lemma 2.2(i)), and by the halving law it falls by at least one bit per additional bit of model complexity, possibly in sudden drops. It first meets the sufficiency line at the minimal sufficient statistic, of complexity \(\mathrm{soph}(x)\), and follows the line from there on. The region above the curve is the profile \(P_x\) of all pairs \((\alpha,\log|S|)\) achieved by models \(S\ni x\). For a stochastic string the curve drops to the sufficiency line almost at once; for an antistochastic string it follows \(n-\alpha\) until \(\alpha\approx C(x)\).

2.2 Strong models and partitions

Definition 2.3 ([11, 7]). A model \(A\ni x\) is \(\varepsilon\)-strong if \(\mathit{CT}(A\mid x)\le\varepsilon\), and \(h^{\mathrm{str}}_{x,\varepsilon}(\alpha)=\min\{\log|A| : x\in A,\ \mathit{CT}(A\mid x)\le\varepsilon,\ C(A)\le\alpha\}\). A string is \((\varepsilon,\delta)\)-normal if \(h^{\mathrm{str}}_{x,\varepsilon}(\alpha+\delta)\le h_x(\alpha)+\delta\) for all \(\alpha\), and strange if it has no strong minimal sufficient statistic.

Strong models exclude the universal models of [2], which carry the information of the number of strings of bounded complexity [11]. Strange strings exist [11]; normal strings exist for every admissible shape [7]; antistochastic strings are normal [7]. The following lemma is the bridge to partitions.

Lemma 2.4 (Partition lemma [7]). If \(A\ni x\) is \(\varepsilon\)-strong, there is a partition \(p\) of \(\{0,1\}^n\) with \(C(p)\le\varepsilon+O(\log n)\) and a cell \(A_1\ni x\) of \(p\) with \(A_1\subseteq A\) and \(C(A_1)\le C(A)+\varepsilon+O(\log n)\).

Proof. Let \(r\) be a total program with \(r(x)=A\) and \(|r|\le\varepsilon\). Group the strings \(x'\) with \(x'\in r(x')\) according to the value \(r(x')\), and put every other string in a singleton cell. This partition is computable from \(r\) and \(n\), and the cell of \(x\) is \(A_1=\{x''\in A : r(x'')=A\}\), computable from \(A\), \(r\) and \(n\). ◻

2.3 Restricted model classes

For a family \(\mathcal{A}\) of finite sets, the restricted structure function \(h^{\mathcal{A}}_x(\alpha)=\min\{\log|A| : x\in A\in\mathcal{A},\ C(A)\le\alpha\}\) uses only models from \(\mathcal{A}\), and \(\mathrm{soph}^{\mathcal{A}}(x)\) is defined from it as \(\mathrm{soph}(x)\) is from \(h_x\). The family is acceptable [14] (see also [7, 9]) if it is enumerable, contains every \(\{0,1\}^n\), and satisfies the covering condition: for a fixed polynomial \(\rho\), every \(A\in\mathcal{A}\) and every \(c<|A|\), the \(n\)-bit strings of \(A\) are covered by at most \(\rho(n)|A|/c\) members of \(\mathcal{A}\) of size at most \(c\).

Theorem 2.5 ([14]). If \(\mathcal{A}\) is acceptable, \(h^{\mathcal{A}}_x\) obeys the halving law, and for every admissible shape \(P\) there is \(x\) with \(h_x\) and \(h^{\mathcal{A}}_x\) both \(C(P)+O(\sqrt{n\log n})\)-close to \(P\).

3 The Galois connection

3.1 Symmetric partitions

Fix an ambient finite group \(G\) acting on a finite set \(X\), with \(G=G_n\) computable from \(n\) when \(X=\{0,1\}^n\). Let \(L(G)\) be the subgroup lattice and \(\mathrm{Par}(X)\) the partition lattice, ordered by refinement (\(p\le q\) if every cell of \(p\) lies in a cell of \(q\)). Put \[\mathrm{orb}_G(U)=\{\text{orbits of }U\},\qquad \mathrm{stab}_G(p)=\{g\in G : g(B)=B\text{ for every cell }B\in p\}.\]

Proposition 3.1 ([3]). \(\mathrm{orb}_G(U)\le p\iff U\le\mathrm{stab}_G(p)\). Hence both maps are monotone, \(U\le\mathrm{stab}_G\mathrm{orb}_G(U)\), \(\mathrm{orb}_G\mathrm{stab}_G(p)\le p\), and the closed subgroups (\(U=\mathrm{stab}_G\mathrm{orb}_G U\)) correspond bijectively and order-preservingly to the symmetric partitions (\(p=\mathrm{orb}_G\mathrm{stab}_G p\)), which are exactly the orbit partitions of subgroups of \(G\). Denote their lattice by \(\mathrm{Par}_G\).

Proof. If every \(U\)-orbit lies in a cell of \(p\), each cell is a union of \(U\)-orbits and is \(U\)-invariant; conversely, if \(U\) preserves every cell its orbits lie in cells. The rest is the general theory of Galois connections. ◻

The closed subgroup \(\mathrm{stab}_G(p)\) is the largest subgroup with orbit partition \(p\): the canonical certificate of the hypothesis \(p\).

Example 3.2.

  1. \(G=\mathrm{Sym}(X)\): every partition is symmetric, and the canonical certificates are the Young subgroups \(\prod_{B\in p}\mathrm{Sym}(B)\).

  2. \(G=S_n\) permuting the coordinates of \(\{0,1\}^n\): \(\mathrm{orb}(S_n)\) is the partition into weight classes; subgroups give finer “combinatorial” partitions.

  3. \(G=\mathrm{GL}(n,2)\): symmetric partitions are rigid. If \(W\ne\mathbb{F}_2^n\) is a subspace with \(\dim W\ge2\), the partition \(\{W\setminus\{0\}\}\cup\{\text{singletons}\}\) is not symmetric: any \(g\) preserving it fixes every vector outside \(W\setminus\{0\}\), these span \(\mathbb{F}_2^n\), so \(g=1\). With a canonical complement \(D\), the orbit partition of \(\mathrm{GL}(W)\times\{\mathrm{id}_D\}\) is symmetric; its cells are \(\{d\}\) and \(d+(W\setminus\{0\})\), \(d\in D\). A cell can appear only together with the other orbits of its certificate.

3.2 Canonical cost

\(C(p)\) is the complexity of a partition \(p\) of \(\{0,1\}^n\) as a finite object, \(C(p,B)\) that of \(p\) with one of its cells, and \(C(U)\) the complexity of a generator list of \(U\).

Proposition 3.3 (Canonical cost). For \(U\le G\) with \(p=\mathrm{orb}_G(U)\) and a cell \(B\) of \(p\): \[C(\mathrm{stab}_G p)\le C(p)+O(1)\le C(U)+O(1),\qquad C(\mathrm{stab}_G p,B)=C(p,B)\pm O(1).\] The canonical certificate is, up to \(O(1)\), the cheapest group with the given orbits, and it costs exactly as much as the hypothesis.

Proof. Orbits are computable from generators; \(\mathrm{stab}_G(p)\) is computable from \(p\) by search in \(G_n\), and \(n\) is recoverable from \(p\). ◻

3.3 Cells: homogeneous sets

A structure function sees a hypothesis only through the cell containing \(x\) and the cost of naming it. So the basic question is which sets occur as cells. Write \(G_{\{S\}}=\{g\in G: g(S)=S\}\) for the setwise stabiliser of \(S\subseteq X\).

Definition 3.4. A set \(S\subseteq X\) is \(G\)-homogeneous if \(G_{\{S\}}\) acts transitively on \(S\). Let \(\mathcal{A}_G\) denote the family of non-empty \(G\)-homogeneous subsets of \(X\).

Proposition 3.5 (Cells). Let \(S\subseteq X\) be non-empty.

  1. \(S\) is a cell of some partition in \(\mathrm{Par}_G\) if and only if \(S\in\mathcal{A}_G\).

  2. If \(S\in\mathcal{A}_G\), then \(p_S=\mathrm{orb}_G(G_{\{S\}})\) is the coarsest partition in \(\mathrm{Par}_G\) having \(S\) as a cell: every \(p\in\mathrm{Par}_G\) with \(S\in p\) refines \(p_S\).

  3. If \(S\in\mathcal{A}_G\), then \(C(p_S,S)=C(S)\pm O(1)\). For every partition \(p\) having \(S\) as a cell, \(C(S)\le C(p,S)+O(1)\).

Proof. (i) If \(S=U\cdot x\) for some \(U\le G\), then \(U\le G_{\{S\}}\), so \(G_{\{S\}}\) is transitive on \(S\). Conversely, if \(G_{\{S\}}\) is transitive on \(S\), then \(S\) is one of its orbits, hence a cell of \(p_S\), which is symmetric by Proposition 3.1. (ii) If \(p\in\mathrm{Par}_G\) and \(S\in p\), then \(\mathrm{stab}_G(p)\le G_{\{S\}}\), so \(p=\mathrm{orb}_G\mathrm{stab}_G(p)\le\mathrm{orb}_G(G_{\{S\}})=p_S\) because \(\mathrm{orb}_G\) is monotone. (iii) \(G_{\{S\}}\), and hence \(p_S\), is computable from \(S\) by search in \(G_n\), and \(n\) is recoverable from \(S\). Conversely \(S\) is computable from \((p,S)\). ◻

So a cell carries its own canonical hypothesis, and naming the cell already names that hypothesis. Whole symmetric partitions are rigid (Example 3.2(c)), but single cells are constrained only by homogeneity.

Example 3.6.

  1. \(G=\mathrm{Sym}(X)\): every non-empty set is homogeneous, and \(p_S\) is \(\{S,X\setminus S\}\) (or \(\{X\}\) if \(S=X\)).

  2. \(G=\mathrm{GL}(n,2)\): a homogeneous set containing \(0\) is \(\{0\}\), since \(0\) is fixed. Theorem 6.3 identifies the others.

  3. \(G=\mathrm{GL}(3,2)\): \(79\) of the \(255\) non-empty subsets of \(\mathbb{F}_2^3\) are homogeneous, distributed by size \(1,\dots,8\) as \(8,21,35,7,0,7,1,0\). Every pair and every triple of nonzero vectors is homogeneous, and no \(5\)-set is. Only \(100\) of the \(4140\) partitions of \(\mathbb{F}_2^3\) are symmetric, but \(695\) have every cell homogeneous. See Figure 2.

3.4 The algebra of hypotheses

Since \(\mathrm{orb}_G\) is a lower adjoint it preserves joins, and \(\mathrm{stab}_G\) as an upper adjoint preserves meets: \[\mathrm{orb}_G(\langle U,V\rangle)=\mathrm{orb}_G(U)\vee\mathrm{orb}_G(V),\qquad \mathrm{stab}_G(p\wedge q)=\mathrm{stab}_G(p)\cap\mathrm{stab}_G(q).\] So \(\mathrm{Par}_G\) is closed under joins in \(\mathrm{Par}(X)\): the join of two hypotheses is the hypothesis of all their symmetries together, and is coarser. The meet in \(\mathrm{Par}_G\) is \(p\wedge_G q=\mathrm{orb}_G(\mathrm{stab}_G p\cap\mathrm{stab}_G q)\le p\wedge q\), the hypothesis of their common symmetries, which is finer. Both are computable, so \(C(p\vee q),C(p\wedge_G q)\le C(p)+C(q)+O(\log n)\). The cell of \(x\) in \(p\wedge_G q\) lies inside the intersection of its cells in \(p\) and \(q\). Meeting with a second cheap hypothesis is thus the natural way to sharpen an explanation (compare the paragraph on halving at the end of Section 7 and Question 7.2).

3.5 Relabelling

\(G\) acts by conjugation on \(L(G)\) and by translation on \(\mathrm{Par}_G\), and the two maps are equivariant: \[\mathrm{orb}_G(gUg^{-1})=g\cdot\mathrm{orb}_G(U),\qquad \mathrm{stab}_G(g\cdot p)=g\,\mathrm{stab}_G(p)\,g^{-1}.\] The model \((g\cdot p,gB)\) for \(gx\) is the model \((p,B)\) for \(x\) in new coordinates, and costs at most \(C(g)+O(1)\) more.

4 Partition structure functions

Definition 4.1. Let \(\mathcal{P}\) assign to each \(n\) a family of partitions of \(\{0,1\}^n\). A \(\mathcal{P}\)-model for \(x\) is a pair \((p,B)\) with \(p\in\mathcal{P}\) and \(x\in B\in p\). Define \[\begin{aligned} h^{\mathcal{P}}_x(\alpha)&=\min\{\log|B| : (p,B)\ \mathcal{P}\text{-model},\ C(p,B)\le\alpha\},\\ h^{\mathcal{P}}_{x,\varepsilon}(\alpha)&=\min\{\log|B| : (p,B)\ \mathcal{P}\text{-model},\ C(p)\le\varepsilon,\ C(p,B)\le\alpha\},\\ \mathrm{soph}^{\mathcal{P}}(x)&=\min\{\alpha : h^{\mathcal{P}}_x(\alpha)+\alpha\le C(x)+c\log n\}. \end{aligned}\] \(C(p)\) is the cost of the hypothesis and \(C(B\mid p)\) that of the cell; \(C(p,B)=C(p)+C(B\mid p)\) up to \(O(\log n)\). For an ambient group \(G\) we write \(h^G_x\), \(h^G_{x,\varepsilon}\) and \(\mathrm{soph}^G\) for \(\mathcal{P}=\mathrm{Par}_G\).

Proposition 4.2. Up to \(O(1)\) shifts: (i) \(h_x\le h^{\mathcal{P}}_x\le h^{\mathcal{P}}_{x,\varepsilon}\), and \(\mathcal{P}\subseteq\mathcal{P}'\) implies \(h^{\mathcal{P}'}_x\le h^{\mathcal{P}}_x\); (ii) every cell of a partition of complexity at most \(\varepsilon\) is \((\varepsilon+O(1))\)-strong, so \(h^{\mathrm{str}}_{x,\varepsilon+c}\le h^{\mathcal{P}}_{x,\varepsilon}\); (iii) \(\mathrm{soph}(x)\le\mathrm{soph}^{\mathcal{P}}(x)\) up to \(O(\log n)\).

Proof. (i) A cell is a finite set containing \(x\) and \(C(B)\le C(p,B)+O(1)\). (ii) A total program knowing \(p\) maps \(x\) to its cell. (iii) Follows from (i). ◻

Corollary 4.3 (Cells suffice). For every ambient \(G\), up to \(O(1)\) shifts in \(\alpha\), \[h^G_x=h^{\mathcal{A}_G}_x\qquad\text{and}\qquad \mathrm{soph}^G(x)=\mathrm{soph}^{\mathcal{A}_G}(x).\]

Proof. A \(\mathrm{Par}_G\)-model \((p,B)\) has \(B\in\mathcal{A}_G\) and \(C(B)\le C(p,B)+O(1)\). A set \(B\in\mathcal{A}_G\) containing \(x\) gives the \(\mathrm{Par}_G\)-model \((p_B,B)\) with \(C(p_B,B)\le C(B)+O(1)\). Both by Proposition 3.5. ◻

The strong version does not reduce to cells in the same way. The canonical hypothesis satisfies \(C(p_B)\le C(B)+O(1)\), but this can exceed the cost of the cheapest symmetric partition containing \(B\) by up to \(C(B\mid p)\le\log|p|\le n\) bits. So \(h^G_{x,\varepsilon}\) depends on which cheap partitions carry \(B\), not only on \(B\) (compare Question 10.1).

Groups and partitions.

The group formulation defines \(h^{L(G)}_x(\alpha)\) as the least \(\log|U\cdot x|\) over subgroups \(U\le G\) with \(C(U,U\cdot x)\le\alpha\), and \(h^{L(G)}_{x,\varepsilon}\) by adding \(C(U)\le\varepsilon\).

Theorem 4.4 (Dictionary). For every ambient \(G\), up to \(O(1)\) shifts in \(\alpha\) and \(\varepsilon\), \(h^{L(G)}_x=h^G_x\) and \(h^{L(G)}_{x,\varepsilon}=h^G_{x,\varepsilon}\).

Proof. A pair \((U,U\cdot x)\) gives the \(\mathrm{Par}_G\)-model \((\mathrm{orb}_G U,U\cdot x)\) at no greater cost. A \(\mathrm{Par}_G\)-model \((p,B)\) gives \((\mathrm{stab}_G p,B)\), and \(\mathrm{stab}_G(p)\cdot x=B\) because \(p\) is symmetric. Costs are compared by Proposition 3.3. ◻

Proposition 4.5 (Burnside form). 5 All permutations

Let \(\mathrm{Sym}\) denote the ambient group \(\mathrm{Sym}(\{0,1\}^n)\), written \(S_X\) with \(X=\{0,1\}^n\) in Section 9. By Example 3.2(a), \(\mathrm{Par}_{\mathrm{Sym}}\) is the lattice of all partitions, and by Example 3.6(a) every non-empty set is a cell.

Theorem 5.1. Up to \(O(1)\) shifts, \(h^{\mathrm{Sym}}_x=h_x\), so \(\mathrm{soph}^{\mathrm{Sym}}=\mathrm{soph}\). Up to \(O(\varepsilon+\log n)\) shifts, \(h^{\mathrm{Sym}}_{x,\varepsilon}=h^{\mathrm{str}}_{x,\varepsilon}\).

Proof. Every set is \(\mathrm{Sym}\)-homogeneous, so the first claim is Corollary 4.3; explicitly, for \(S\ni x\) the partition \(\{S,X\setminus S\}\) costs \(C(S)+O(1)\). For the second claim combine Proposition 4.2(ii) with the partition lemma (Lemma 2.4). ◻

Corollary 5.2. Up to \(O(\varepsilon+\delta+\log n)\), a string is \((\varepsilon,\delta)\)-normal if and only if cells of partitions of complexity at most \(\varepsilon\) (equivalently, orbits of groups of complexity at most \(\varepsilon\)) are as good as arbitrary models at every level. It is strange if and only if no such cell is a minimal sufficient statistic. So there are strings with no sufficient cheap symmetry explanation [11], and every admissible shape is realised by a string whose cheap-symmetry structure function equals its Kolmogorov structure function [7].

Theorem 5.1 says that unrestricted symmetry explains everything. As a statement about symmetry this is nearly vacuous. The canonical certificates in \(S_X\) are Young subgroups, whose type records only the sizes of the cells. In the coordinates of Section 9, a model of complexity much larger than \(2^{n/2}\) has all but \(O(2^{n/2})\) bits of its information in the placement of its certificate, under every realisation (Proposition 9.4). Moreover, the canonical certificate in \(S_X\) can hide a genuinely structured symmetry (Example 9.5).

6 Linear symmetry

Identify \(\{0,1\}^n\) with \(\mathbb{F}_2^n\) and take \(G=\mathrm{GL}(n,2)\). Linear maps fix \(0\), so throughout \(x\ne0\).

6.1 Cells: linearly homogeneous sets

Which sets can be cells of linear-symmetric partitions? A linear map preserves all \(\mathbb{F}_2\)-linear dependencies, so a set can be an orbit of a linear group only if its internal dependency structure looks the same from each of its points. We make this precise.

A relation in \(S\subseteq\mathbb{F}_2^n\setminus\{0\}\) is a subset \(T\subseteq S\) with \(\sum T=0\), an XOR dependency among elements of \(S\). For example, in \(S=\{e_1,e_2,e_1+e_2\}\) the whole set is a relation, since \(e_1+e_2+(e_1+e_2)=0\). The family of all relations is the dependency structure of \(S\) (the binary matroid it represents). A permutation \(\pi\) of \(S\) preserves relations if \(\sum T=0\iff\sum\pi(T)=0\) for all \(T\subseteq S\), i.e. if it is an automorphism of the dependency structure.

Definition 6.1. A set \(S\subseteq\mathbb{F}_2^n\setminus\{0\}\) is linearly homogeneous if the relation-preserving permutations of \(S\) act transitively on \(S\): for any \(s,s'\in S\) some automorphism of the dependency structure maps \(s\) to \(s'\).

The analogy is with vertex-transitive graphs, where every vertex looks alike; here every point looks alike with respect to XOR dependencies instead of edges. Two extreme cases show the range of the notion. A linearly independent set has no relations, so every permutation preserves them and the set is homogeneous. A punctured subspace \(W\setminus\{0\}\) has as many relations as possible, but \(\mathrm{GL}(W)\) moves any nonzero vector to any other while preserving them, so it too is homogeneous. Homogeneity fails when some points play special roles.

Example 6.2. Linearly homogeneous sets include: \(W\setminus\{0\}\) for a subspace \(W\); affine subspaces \(a+W\) with \(a\notin W\); linearly independent sets; weight classes and other orbits of coordinate permutation groups; and cosets of multiplicative subgroups of \(\mathbb{F}_{2^n}^\times\), identifying \(\mathbb{F}_2^n\) with \(\mathbb{F}_{2^n}\). The set \(\{e_1,e_2,e_1+e_2,e_3\}\) is not homogeneous: \(e_1\) lies in the three-term relation \(\{e_1,e_2,e_1+e_2\}\) while \(e_3\) lies in no relation, so no relation-preserving permutation maps \(e_1\) to \(e_3\). Figure 3 shows orbits of several subgroups of \(\mathrm{GL}(4,2)\).

The key fact is a small piece of linear algebra: a permutation of \(S\) extends to an invertible linear map if and only if it preserves relations. This gives the characterisation of cells.

Theorem 6.3. Let \(S\subseteq\mathbb{F}_2^n\setminus\{0\}\). Every relation-preserving permutation of \(S\) is the restriction of an element of \(\mathrm{GL}(n,2)_{\{S\}}\). Hence \(S\) is \(\mathrm{GL}\)-homogeneous if and only if it is linearly homogeneous, and \(\mathcal{A}_{\mathrm{GL}}\) consists of \(\{0\}\) and the linearly homogeneous sets. By Corollary 4.3, \(h^{\mathrm{GL}}_x\) is Kolmogorov’s structure function restricted to linearly homogeneous sets.

Proof. The restriction of a linear map preserves relations. Conversely, a relation-preserving \(\pi\) defines a linear bijection \(L_\pi(\sum_{s\in T}s)=\sum_{s\in T}\pi(s)\) of \(\mathrm{span}(S)\). It is well defined, because \(\sum T=\sum T'\) implies \(\sum(T\triangle T')=0\) and hence \(\sum\pi(T)=\sum\pi(T')\), and it is injective, because \(\pi^{-1}\) also preserves relations. Extending \(L_\pi\) by the identity on a complement of \(\mathrm{span}(S)\) gives \(g\in\mathrm{GL}(n,2)\) with \(g(S)=S\) and \(g|_S=\pi\). So the restrictions of \(\mathrm{GL}(n,2)_{\{S\}}\) to \(S\) are exactly the relation-preserving permutations, and one group is transitive on \(S\) if and only if the other is. Since linear maps fix \(0\), a homogeneous set containing \(0\) is \(\{0\}\). ◻

Why this matters.

By Corollary 4.3 and Theorem 6.3, \(h^{\mathrm{GL}}_x\) is Vereshchagin and Vitányi’s structure function for the concrete model class \(\mathcal{A}_{\mathrm{GL}}\) of linearly homogeneous sets [14], so the groups drop out of the definition. Since a homogeneous set determines its own certificate (Proposition 3.5), describing the group costs nothing extra, and every difference between \(h^{\mathrm{GL}}_x\) and \(h_x\) comes from which sets are admissible. Under \(\mathrm{Sym}(\{0,1\}^n)\) every set qualifies (Theorem 5.1). Under \(\mathrm{GL}(n,2)\) only homogeneous sets do, and there are at most \(2^{n^4+n}\) of them against \(2^{2^n}\) arbitrary sets. This scarcity is what the band (Section 7) measures and what the counting proof of Theorem 8.2 exploits. Membership in \(\mathcal{A}_{\mathrm{GL}}\) is a finite test, namely transitivity of the setwise stabiliser. However, half of a homogeneous set is usually not homogeneous, so the halving law for \(h^{\mathrm{GL}}_x\) is a genuine open question (Question 7.2).

Single cells are constrained only by homogeneity, but whole symmetric partitions are rigid (Example 3.2(c)). This matters for the strong version \(h^{\mathrm{GL}}_{x,\varepsilon}\), which requires a cheap symmetric partition containing the cell (Question 10.1). Linear hypotheses also have little room to hide information in placement: a subgroup of \(\mathrm{GL}(n,2)\) is determined by its type, an abstract group with a faithful module, up to \(n^2\) bits (Proposition 9.6).

6.2 Affine hypotheses

Every affine subspace is a cell of a cheap symmetric partition. For \(W\setminus\{0\}\) this is Example 3.2(c). For \(a+W\) with \(a\notin W\), fix a complement \(D\) of \(W\oplus\langle a\rangle\), and for \(w\in W\) let \(\tau_w\) fix \(W\oplus D\) pointwise and send \(a\mapsto a+w\). The group \(\{\tau_w\}\cong W\) has cells \(\{v\}\) for \(v\in W\oplus D\) and \(a+d+W\) for \(d\in D\), at cost \(C(W,a)+O(1)\). Writing \(h^{\mathrm{aff}}_x\) for the structure function over affine subspaces, we get, up to \(O(\log n)\), \[\tag{6.1} h_x\ \le\ h^{\mathrm{GL}}_x\ \le\ h^{\mathrm{aff}}_x,\qquad h_x\ \le\ h^{\mathrm{str}}_{x,\varepsilon}\ \le\ h^{\mathrm{GL}}_{x,\varepsilon}.\]

7 The band

Theorem 7.1 (Band). Let \(x\in\mathbb{F}_2^n\setminus\{0\}\) with \(C(x)=\kappa\). Up to \(O(\log n)\):

  1. \(\kappa-\alpha\le h_x(\alpha)\le h^{\mathrm{GL}}_x(\alpha)\le h^{\mathrm{aff}}_x(\alpha)\le n-\alpha\) for \(c\log n\le\alpha\le\kappa\);

  2. \(h^{\mathrm{GL}}_x(c\log n)\le\log(2^n-1)\) and \(h^{\mathrm{GL}}_x(\kappa)=0\);

  3. \(0\le h^{\mathrm{GL}}_x(\alpha)-h_x(\alpha)\le n-\kappa\), and \(\mathrm{soph}(x)\le\mathrm{soph}^{\mathrm{GL}}(x)\le\kappa\);

  4. (relabelling) for \(g\in\mathrm{GL}(n,2)\), \(h^{\mathrm{GL}}_{gx}(\alpha+C(g)+c)\le h^{\mathrm{GL}}_x(\alpha)\).

Proof. (i) By Lemma 2.2(i) and (6.1); for the last inequality use the affine subspace of strings agreeing with \(x\) in the first \(j\) coordinates. (ii) Use the partitions \(\{\{0\},\mathbb{F}_2^n\setminus\{0\}\}\) and the discrete partition. (iii) Follows from (i) and (ii). (iv) By equivariance of the Galois connection. ◻

All the structure functions together.

Figure 5 places the structure functions of this paper in one picture, for a typical normal string \(x\) of length \(n\) with \(\kappa=C(x)\). Normal strings are the common case. A stochastic string has a simple, hence strong, sufficient model, so strangeness forces non-stochasticity, and non-stochastic strings have small a priori probability [12]. The figure shows six curves, of which three coincide for normal strings, together with two guide lines and three marked points. It should be read as follows.

  1. The guides. The lower dashed line is the sufficiency line \(\kappa-\alpha\), and the upper one is the ceiling \(n-\alpha\). By Lemma 2.2(i) and Theorem 7.1(i), every curve in the figure lies between them for \(c\log n\le\alpha\le\kappa\), up to \(O(\log n)\). A model on the sufficiency line is sufficient; a curve on the ceiling means that the models of that kind are no better than those of a random string of length \(n\).

  2. The order of the curves (proved for every \(x\)). By Proposition 4.2, up to \(O(1)\) shifts, \[h_x\le h^{\mathrm{str}}_{x,\varepsilon}\le h^{\mathrm{GL}}_{x,\varepsilon},\qquad h_x\le h^{\mathrm{GL}}_x\le h^{\mathrm{GL}}_{x,\varepsilon}.\] The cheap linear-symmetry curve pays for two restrictions at once: its models must be linear-symmetric and strong.

  3. The endpoints (proved for every \(x\)). At the cheapest budget every curve is at most \(n\): the one-cell partition and the partition \(\{\{0\},\mathbb{F}_2^n\setminus\{0\}\}\) cost \(O(\log n)\). At \(\alpha\approx\kappa\) every curve vanishes, since the discrete partition is cheap and its cell \(\{x\}\) costs \(\kappa\). All differences between the curves occur for \(c\log n\le\alpha\le\kappa\).

  4. Kolmogorov’s curve \(h_x\) (solid blue) has the typical shape of Figure 1. It starts on the ceiling, decreases by at least one bit per bit of budget (the halving law), with two sudden drops, and first meets the sufficiency line at its minimal sufficient statistic (blue dot), of complexity \(\mathrm{soph}(x)\). From there it follows the sufficiency line down to \(\alpha=\kappa\).

  5. The unrestricted symmetric curve \(h^{\mathrm{Sym}}_x\) (red dots) lies on \(h_x\) for every string, not only for normal ones. This is the collapse of Theorem 5.1: every finite set is a cell of a partition symmetric under \(\mathrm{Sym}(\{0,1\}^n)\), at no extra cost. In particular \(\mathrm{soph}^{\mathrm{Sym}}(x)=\mathrm{soph}(x)\), and the two tick labels at the blue dot coincide. The coincidence is nearly uninformative about symmetry: by Proposition 9.4 the canonical certificates are Young subgroups whose type records only cell sizes, so for complex models the information sits in the placement.

  6. The strong curve \(h^{\mathrm{str}}_{x,\varepsilon}\) (green dashes) also lies on \(h_x\). This is the definition of normality: every point of the profile is attained by an \(\varepsilon\)-strong model, up to \(\delta\). By Theorem 5.1 the same curve is the cheap unrestricted symmetric curve \(h^{\mathrm{Sym}}_{x,\varepsilon}\). For a strange string it would separate from \(h_x\) and lie above it, while \(h^{\mathrm{Sym}}_x\) would still lie on \(h_x\).

  7. The linear-symmetry curve \(h^{\mathrm{GL}}_x\) (solid violet) uses cells of symmetric partitions of \(\mathrm{GL}(n,2)\) of any cost, that is, linearly homogeneous sets (Theorem 6.3). In the figure it follows the ceiling up to \(\alpha\approx\kappa/2\): at those budgets no linear symmetry sees any structure of \(x\). It then drops, decreases along a segment of slope \(-1\), drops again, and first meets the sufficiency line at the violet dot, whose complexity is the symmetric sophistication \(\mathrm{soph}^{\mathrm{GL}}(x)\). By Theorem 7.1(iii), \(\mathrm{soph}(x)\le\mathrm{soph}^{\mathrm{GL}}(x)\le\kappa\).

  8. The symmetry gap (shaded) is the region between \(h_x\) and \(h^{\mathrm{GL}}_x\). At each budget it is the part of the regularity of \(x\) that linear symmetry does not see. Its horizontal extent at the sufficiency line, \(\mathrm{soph}^{\mathrm{GL}}(x)-\mathrm{soph}(x)\), is the extra budget symmetric explanations need before they become sufficient. By Corollary 8.1 the region can be empty, with \(h^{\mathrm{GL}}_x=h_x\). By Theorem 8.2 it can fill the whole band, with \(h^{\mathrm{GL}}_x\) on the ceiling up to \(\alpha\approx\kappa\), even for stochastic normal strings.

  9. The cheap linear-symmetry curve \(h^{\mathrm{GL}}_{x,\varepsilon}\) (orange dashes) uses only cells of symmetric partitions of complexity at most \(\varepsilon\). In the figure it agrees with \(h^{\mathrm{GL}}_x\) on the ceiling, where the cylinder partitions fixing the first \(j\) coordinates are cheap, and lies above it afterwards. There the good linear-symmetric cells of \(x\) exist only inside expensive symmetric partitions: the rigidity effect of Question 10.1. It meets the sufficiency line only at the right end, just before \(\alpha=\kappa\). Because \(x\) is normal, this separation from \(h^{\mathrm{GL}}_x\) is caused by symmetry, not by strangeness.

  10. The marked points. On the horizontal axis: \(\mathrm{soph}(x)\), equal to \(\mathrm{soph}^{\mathrm{Sym}}(x)\), where \(h_x\) and \(h^{\mathrm{Sym}}_x\) become sufficient; \(\mathrm{soph}^{\mathrm{GL}}(x)\), where \(h^{\mathrm{GL}}_x\) becomes sufficient; and \(\kappa\), where all curves vanish. On the vertical axis: \(n\), where all curves start, and \(\kappa\), where the sufficiency line starts.

Items (1)–(6) and the inequality in (7) are theorems; item (10) only names the marked points. The particular shapes of \(h^{\mathrm{GL}}_x\) and \(h^{\mathrm{GL}}_{x,\varepsilon}\) are illustrative. Which shape is typical is open, and so is whether the rigidity separation in (9) occurs at all. Whether the \(\mathrm{GL}\) curves obey the halving law (Question 7.2) is also open. If they do not, they may have plateaus, which \(h_x\) never has.

Halving as refinement.

Affine subspaces form an acceptable class: a coset of dimension \(d\) splits into at most \(2|A|/c\) cosets of size at most \(c\). By Theorem 2.5, \(h^{\mathrm{aff}}_x\) obeys the halving law. For \(h^{\mathrm{GL}}_x\) the question becomes one about the lattice \(\mathrm{Par}_{\mathrm{GL}}\). Given a symmetric \(p\) with \(x\in B\in p\), is there a cheap symmetric refinement whose cell containing \(x\) has size about \(|B|/2\)? The algebra of Section 3 suggests meeting \(p\) with a second cheap hypothesis \(q\): the cell of \(x\) in \(p\wedge_{\mathrm{GL}}q\) lies in the intersection of its cells. Transitivity alone does not obstruct this. \(\mathrm{GL}(n,2)\) is \(2\)-transitive on nonzero vectors, so no subgroup between \(\mathrm{stab}(x)\) and \(\mathrm{GL}(n,2)\) refines the orbit of \(x\), but subgroups not containing \(\mathrm{stab}(x)\) can. Since linear maps fix \(0\), homogeneous sets other than \(\{0\}\) avoid \(0\), so \(\mathcal{A}_{\mathrm{GL}}\) contains \(\mathbb{F}_2^n\setminus\{0\}\) rather than the whole space required in the definition of acceptability; this changes nothing up to \(O(1)\).

Question 7.2. Is \(\mathcal{A}_{\mathrm{GL}}\) acceptable, i.e. can every \(S\in\mathcal{A}_{\mathrm{GL}}\) of size \(N\) be covered by \(\mathrm{poly}(n)\,N/c\) members of \(\mathcal{A}_{\mathrm{GL}}\) of size at most \(c\)? In the language of Section 3.4: does every cell admit cheap symmetric refinements, for instance by meets? If not, does \(h^{\mathrm{GL}}_x\) exhibit a plateau for some \(x\)?

8 The extremes of the band

8.1 Zero gap: symmetry explains everything

Corollary 8.1. For every admissible shape \(P\) there is a string \(x\) with \(h_x\approx h^{\mathrm{GL}}_x\approx h^{\mathrm{aff}}_x\approx P\), up to \(C(P)+O(\sqrt{n\log n})\), so \(\mathrm{soph}^{\mathrm{GL}}(x)=\mathrm{soph}(x)\) to the same accuracy.

Proof. Theorem 2.5 applied to affine subspaces, and (6.1). ◻

8.2 Maximal gap: structure invisible to symmetry

Theorem 8.2 (Maximal gap). There is a constant \(c\) such that for all \(n\), all \(c\log n\le m\le n\) and all \(t\ge0\) there are strings \(x\in\{0,1\}^n\) with:

  1. \(C(x)=m\pm O(t+\log n)\) and \(h_x(\alpha)=m-\alpha\pm O(t+\log n)\) for \(c\log n\le\alpha\le m\); \(x\) is stochastic and \((O(\log n),O(t+\log n))\)-normal;

  2. \(h^{\mathrm{GL}}_x(\alpha)\ge n-\alpha-t-O(\log n)\) for all \(\alpha\le m-t-c\log n\).

In fact all but a \(2^{-t}\) fraction of a set \(S\) with \(C(S)=O(\log n)\) and \(|S|\approx2^m\) have these properties.

Proof. Counting cells. By Proposition 9.6, or simply because a group of order \(N\) has a generating set of size \(\log N\), there are at most \(2^{n^4}\) subgroups of \(\mathrm{GL}(n,2)\), hence at most \(2^{n^4+n}\) cells of symmetric partitions.

A set that no cell sees. Put each string into a random \(S\) independently with probability \(2^{m-n}\). For a cell \(B\) let \(R_B=\max(2e\,2^{m-n}|B|,n^5)\). The Chernoff bound \(\Pr[X\ge R]\le2^{-R}\) for \(R\ge2e\,\mathbb{E}X\) [8] gives \(\Pr[|S\cap B|\ge R_B]\le2^{-n^5}\). A union bound, and concentration of \(|S|\), show that with positive probability \[\tag{8.1} 2^{m-1}\le|S|\le2^{m+1}\quad\text{and}\quad |S\cap B|<\max(2e\,2^{m-n}|B|,\,n^5)\ \text{for every cell }B.\] This property is decidable, so the lexicographically first such \(S\) has \(C(S)=O(\log n)\).

Typical elements. All but a \(2^{-t}\) fraction of \(x\in S\) have \(C(x)\ge m-t\); fix one.

(a) Cutting \(S\) into \(2^j\) consecutive pieces gives models of complexity \(j+O(\log n)\) and size at most \(2^{m+1-j}\), each computable from \(x\) by a total program of length \(O(\log n)\). With Lemma 2.2(i) this gives \(h_x\) and normality.

(b) Fix \(\alpha,s\). Fewer than \(2^{\alpha+1}\) models \((p,B)\) have \(C(p,B)\le\alpha\), and the union \(U\) of those cells with \(|B|\le2^s\) is enumerable from \(n,m,\alpha,s\). By (8.1), \(|U\cap S|\le2^{\alpha+1}\max(2e\,2^{m-n+s},n^5)\). If \(x\in U\), then \[m-t\le C(x)\le\log|U\cap S|+O(\log n) \le\alpha+\max(m-n+s,\ 5\log n)+O(\log n).\] For \(\alpha\le m-t-c\log n\) the second branch is impossible, so \(s\ge n-\alpha-t-O(\log n)\). ◻

Corollary 8.3 (Simple structure, invisible to symmetry). If moreover \(m\le n-t-c'\log n\), these strings satisfy \(\mathrm{soph}(x)=O(\log n)\) but \(\mathrm{soph}^{\mathrm{GL}}(x)\ge C(x)-O(t+\log n)\). They are stochastic and normal, yet no cell of a symmetric partition costing less than \(C(x)-O(t+\log n)\) is sufficient: every sufficient symmetric model essentially names \(x\) itself. The gap between the two chains in (6.1) is a symmetry phenomenon, not a computability one.

Proof. By (b), \(h^{\mathrm{GL}}_x(\alpha)+\alpha\ge n-t-O(\log n)>C(x)+c\log n\) for \(\alpha\le m-t-c\log n\). ◻

Remark 1. The argument only uses that the partition family has \(2^{\mathrm{poly}(n)}\) cells and is decidable. So every such family, for instance \(\mathrm{Par}_G\) for any ambient group of order \(2^{\mathrm{poly}(n)}\), has stochastic normal strings that it sees as antistochastic. The construction is not explicit.

9 Coordinates on the space of permutation groups

The Galois connection organises symmetry hypotheses into a lattice. To move through that lattice, and to search it, we need coordinates. This section shows that every permutation group is a Burnside ring element (its type) together with a permutation (its placement), compares the two ambient groups in these terms, and discusses what the maximal gap theorem implies for searching the coordinates for good models.

9.1 The coordinate theorem

We give coordinates on the set of all permutation groups on a finite set \(X\), \(|X|=N\); in our setting \(X=\{0,1\}^n\) and \(N=2^n\). Via the Galois connection of Section 3 these become coordinates on symmetric partitions, and they are used to navigate both spaces. To keep \(G\) for the ambient group, we write \(H\) for the abstract group.

A subgroup \(U\le S_X\) is the image of a faithful action \(\rho\colon H\to S_X\) of an abstract group \(H\cong U\). Up to isomorphism of \(H\)-sets, the action is determined by its class in the Burnside ring \(B(H)\). Fix representatives \(K_1,\dots,K_r\) of the conjugacy classes of subgroups of \(H\). Then \[[X]_\rho=\sum_{i=1}^r a_i\,[H/K_i],\qquad a_i\ge0,\qquad \deg[X]_\rho:=\sum_i a_i\,|H:K_i|=N .\] The action is faithful iff \(\bigcap_{a_i>0}\mathrm{core}_H(K_i)=1\), where \(\mathrm{core}_H(K)=\bigcap_{h}hKh^{-1}\) is the kernel of \(H\) on \(H/K\). By Burnside’s theorem, \(b\in B(H)\) is determined by its marks \(\varphi_K(b)=|X_b^K|\), the number of points fixed by \(K\).

Definition 9.1 (Canonical realisation). Let \(B_N(H)\) be the set of faithful \(b=\sum a_i[H/K_i]\) of degree \(N\). Fix \(H\) concretely (with a total order on its elements) and the representatives \(K_i\) canonically. For \(b\in B_N(H)\) let \(X_b\) be the disjoint union of \(a_i\) copies of \(H/K_i\), ordered by \(i\), then by copy, then by the least element of each coset. Identify \(X_b\) with \(X\) in lexicographic order. This gives a faithful action \(\rho_b\) and a canonical subgroup \(U_b=\rho_b(H)\le S_X\).

Theorem 9.2 (Coordinates). Let \(\mathcal S_H(X)=\{U\le S_X : U\cong H\}\) and \[\Phi_H\colon B_N(H)\times S_X\to\mathcal S_H(X),\qquad \Phi_H(b,\sigma)=\sigma\,U_b\,\sigma^{-1}.\]

  1. \(\Phi_H\) is surjective: every \(U\cong H\) has coordinates \((b,\sigma)\).

  2. For fixed \(b\), \(\Phi_H(b,\sigma)=\Phi_H(b,\sigma')\) iff \(\sigma^{-1}\sigma'\in N_{S_X}(U_b)\).

  3. \(\Phi_H(b,\sigma)\) and \(\Phi_H(b',\sigma')\) are conjugate in \(S_X\) iff \(b'\in\mathrm{Aut}(H)\cdot b\), where \(\alpha\in\mathrm{Aut}(H)\) acts by \([H/K]\mapsto[H/\alpha(K)]\).

Consequently \[\mathcal S_H(X)\;=\;\bigsqcup_{[b]\in B_N(H)/\mathrm{Aut}(H)} S_X/N_{S_X}(U_b):\] the type \([b]\) is a discrete coordinate labelling conjugacy classes, and the placement \(\sigma\) is a coordinate on the homogeneous space \(S_X/N_{S_X}(U_b)\). The whole space of permutation groups on \(X\) is the disjoint union of these pieces over the isomorphism classes of \(H\) with a faithful action of degree \(N\).

Proof. (i) Fix an isomorphism \(\psi\colon H\to U\). The \(H\)-set \(X\) with action \(\psi\) is faithful of some class \(b\in B_N(H)\), so there is an isomorphism of \(H\)-sets \(\sigma\colon(X,\rho_b)\to(X,\psi)\), i.e. \(\sigma\rho_b(h)\sigma^{-1}=\psi(h)\) for all \(h\). Hence \(U=\sigma U_b\sigma^{-1}\). (ii) This is the definition of the normaliser. (iii) If \(\tau U_b\tau^{-1}=U_{b'}\), then \(\alpha=\rho_{b'}^{-1}\circ c_\tau\circ\rho_b\) is an automorphism of \(H\), and \(\tau\) is an isomorphism of \(H\)-sets from \(X_b\) to \(X_{b'}\) twisted by \(\alpha\), so \(b'=\alpha\cdot b\). The converse reverses the argument. ◻

Partitions and cells in coordinates.

The orbits of \(U_b\) are the summands of \(X_b\), which are consecutive intervals of \(X\). Let \(\lambda(b)\) be the integer partition of \(N\) with part \(|H:K_i|\) repeated \(a_i\) times, and \(p_{\lambda(b)}\) the corresponding partition of \(X\) into consecutive intervals. Then \[\mathrm{orb}\big(\Phi_H(b,\sigma)\big)=\sigma\cdot p_{\lambda(b)} .\] So partitions have coordinates \((\lambda,\sigma)\), with \(\sigma\) defined modulo the stabiliser of \(p_\lambda\) in \(S_X\). The projection \((b,\sigma)\mapsto(\lambda(b),\sigma)\) is \(\mathrm{orb}\) written in coordinates: it forgets the structure of \(b\) beyond its cell sizes. If \(\sigma^{-1}(x)\) lies in a summand of type \(H/K_i\), then the cell of \(x\) has size \(|H:K_i|\), its stabiliser is conjugate to \(K_i\), and \[\Pr_{u\in U}[ux=x]=\frac{|K_i|}{|H|} .\] The marks \(\varphi_K(b)\) give the whole distribution of cell sizes and fixed points over \(X\); Proposition 4.5 is the pointwise case.

Proposition 9.3 (Complexity in coordinates). Let \(U=\Phi_H(b,\sigma)\), with \(b\) chosen canonically in its \(\mathrm{Aut}(H)\)-orbit. Then, up to \(O(\log C(U))\), \[C(U)\;=\;C(H,b)\;+\;\min\{\,C(\sigma'\mid H,b) : \Phi_H(b,\sigma')=U\,\}.\]

Proof. From \(U\) one computes \(H\) up to isomorphism, the canonical \(b\), and the least \(\sigma\) in the coset \(\sigma N_{S_X}(U_b)\). This least element is computable from any member of the coset together with \((H,b)\). Apply symmetry of information. ◻

Navigation.

Two basic moves act on coordinates.

  • Relabelling: \((b,\sigma)\mapsto(b,\pi\sigma)\) conjugates the group by \(\pi\) and translates its partition, at cost at most \(C(\pi)\).

  • Restriction to a subgroup \(L\le H\): the subgroup \(\sigma\rho_b(L)\sigma^{-1}\) has coordinates \((\mathrm{Res}^H_L b,\ \sigma\tau)\) in \(\mathcal S_L(X)\), where \(\tau\) is computable from \((H,L,b)\). Its partition refines that of \(U\) cell by cell, according to the Mackey formula \[\mathrm{Res}^H_L\,[H/K]=\sum_{LhK\in L\backslash H/K} \big[L/(L\cap hKh^{-1})\big],\] so a cell of size \(|H:K|\) splits into cells of sizes \(|L:L\cap hKh^{-1}|\).

Restriction moves down the subgroup lattice and refines hypotheses; relabelling moves within a conjugacy class. In coordinates, the halving question (Question 7.2) asks for a cheap subgroup \(L\le H\) whose Mackey decomposition splits the cell of \(x\) roughly in half.

Remark 2. For subgroups of \(\mathrm{GL}(n,2)\) the same construction applies with \(B(H)\) replaced by the isomorphism classes of faithful \(\mathbb{F}_2H\)-modules of dimension \(n\) (the Green ring), and \(S_X\) by \(\mathrm{GL}(n,2)\). The fibres are then \(\mathrm{GL}(n,2)/N_{\mathrm{GL}(n,2)}(U_b)\), and the placement costs at most \(n^2\) bits (Proposition 9.6).

9.2 Types and placements: \(S_X\) versus \(\mathrm{GL}(n,2)\)

The coordinates separate what a symmetry hypothesis is (its type) from where it sits (its placement). The two ambient groups behave very differently.

Proposition 9.4 (Placement dominates). Let \(S\subseteq X\), and let \(p\) be any partition of \(X\) having \(S\) as a cell (by Example 3.6(a) there are many, the coarsest being \(\{S,X\setminus S\}\)), with canonical certificate \(U=\mathrm{stab}_{S_X}(p)\). Let \(\lambda(p)\) be the multiset of cell sizes of \(p\), an integer partition of \(N=2^n\).

  1. \(U=\prod_{B\in p}\mathrm{Sym}(B)\) is a Young subgroup, and its type \((H,b)\) is determined by \(\lambda(p)\): \(H=\prod_{B\in p}S_{|B|}\), and \(b\) has one orbit of type \(H/H_B\) for each cell \(B\), where \(H_B\) is the stabiliser of a point of \(B\). Hence \[C(H,b)\le C(\lambda(p))+O(1)\le\log P(N)+O(n)=O(2^{n/2}),\] where \(P(N)\) is the number of integer partitions of \(N\).

  2. Every placement realising \(U\) is expensive: \[\min\{C(\sigma\mid H,b) : \Phi_H(b,\sigma)=U\}\ \ge\ C(S)-C(\lambda(p))-O(n).\] In particular the placement carries at least \(C(S)-O(2^{n/2})\) bits, for every partition realising \(S\).

  3. For \(p=\{S\}\cup\{\text{singletons}\}\) with \(|S|=k\ge2\), the type is \(H=S_k\), \(b=[S_k/S_{k-1}]+(2^n-k)[S_k/S_k]\), costing \(O(n)\), and the placement costs \(C(S)\pm O(n)\).

Proof. (i) By Example 3.2(a) the closed subgroups of \(S_X\) are the Young subgroups. A Young subgroup is determined up to conjugacy by its cell sizes, and its abstract group and Burnside ring element are computable from them. Given \(N\), the partition \(\lambda(p)\) is one of \(P(N)\) possibilities, and by the Hardy–Ramanujan formula \(\log_2P(N)\sim\pi\sqrt{2N/3}/\ln2=O(2^{n/2})\). (ii) Since \(U\le S_X\), \(C(U)\le n2^n+O(1)\), so the error term in Proposition 9.3 is \(O(n)\). From \(U\) one computes \(p\), and \(S\) is one of at most \(N\) cells of \(p\). Hence \(C(S)\le C(H,b)+\min C(\sigma\mid H,b)+n+O(n)\); now use (i). (iii) \(S\) is the unique cell of size greater than one, so \(C(U)=C(S)\pm O(1)\), and the type is described by \(k\) and \(n\). ◻

So every symmetric realisation of a model in \(S_X\) has a type that records only cell sizes. Such a type carries at most \(O(2^{n/2})\) bits, and only in the numbers \(|B|\), which is a numerical encoding rather than a symmetry. For a model of complexity much larger than \(2^{n/2}\), which includes typical sets of non-trivial size, the placement carries essentially all the information, under every realisation. For simpler models a suitably chosen partition can move information into the cell sizes, but the abstract group remains a product of full symmetric groups. A symmetry explanation is informative only when its information lies in a type with genuine group-theoretic structure, and the canonical certificates of \(S_X\) never provide one.

Remark 3. The type is cheap, but it is not empty. Write \(b=\sum_i a_i[H/K_i]\). For any ambient group, the cells of \(\Phi_H(b,\sigma)\) have sizes \(|H:K_i|\) with multiplicities \(a_i\), and there are \(\sum_i a_i\) of them. In the three-part description (1.1) this divides the terms between the coordinates: \[C(x)\ \lesssim\ \underbrace{C(H,b)+C(\sigma\mid H,b)}_{\text{hypothesis, }C(p)} \ +\ \underbrace{\log\textstyle\sum_i a_i}_{\text{which cell}} \ +\ \underbrace{\log|H:K_i|}_{\text{noise}},\] where \(i\) is the orbit type of the cell containing \(x\). Both data-to-model terms are read off from the type: it fixes how many cells there are and the multiset of their sizes, and so locates every cell on the vertical axis of the structure function. It does not fix the size of the cell containing \(x\), which depends on the placement, unless all cells have the same size, as for free or transitive actions. For \(S_X\), Proposition 9.4 shows that the division is nearly clean: the type costs \(O(2^{n/2})\) bits and carries the sizes, while the placement carries essentially all of \(C(p)\). A Young subgroup says how large the cells are, and nothing about which sets they are. For \(\mathrm{GL}(n,2)\) the two do not separate in this way, since the type determines the hypothesis up to \(n^2\) bits (Proposition 9.6).

Example 9.5 (The canonical certificate can hide structure). Let \(p_{\mathrm{wt}}\) be the partition of \(\{0,1\}^n\) into weight classes. It is the orbit partition of the coordinate group \(S_n\) permuting bit positions, a small group with structured type \(\sum_{w=0}^n[S_n/(S_w\times S_{n-w})]\). It is also the orbit partition of the Young subgroup \(\prod_w\mathrm{Sym}(\{x:|x|=w\})\), whose type is just the list of binomial coefficients \(\binom nw\). Both certify the same hypothesis at the same canonical cost \(O(\log n)\). With ambient group \(S_X\), however, the Galois connection selects the Young subgroup, so the canonical certificate forgets the symmetry that actually explains the partition. With ambient group \(\mathrm{GL}(n,2)\) the closed subgroup of \(p_{\mathrm{wt}}\) is exactly the group of permutation matrices, since a linear map preserving weight sends each \(e_i\) to some \(e_j\). There the certificate keeps its structure. Figure 6 shows types and placements in \(S_X\) for \(n=3\).

Proposition 9.6 (Type determines the hypothesis up to \(n^2\) bits). Let \(U\le\mathrm{GL}(n,2)\) have coordinates \((b,g)\) as in the remark at the end of Section 9.1: \(b\) is the class of a faithful \(\mathbb{F}_2H\)-module of dimension \(n\) and \(g\in\mathrm{GL}(n,2)\) is a placement. Then, up to \(O(\log n)\), \[C(H,b)\ \le\ C(U)\ \le\ C(H,b)+n^2 .\] Consequently the number of symmetric partitions in \(\mathrm{Par}_{\mathrm{GL}}\) is at most the number of types times \(|\mathrm{GL}(n,2)|\), which is less than \(2^{n^2}\).

Proof. The type is computable from \(U\). Conversely \(U=gU_bg^{-1}\), where \(U_b\) is computable from the type and \(g\) is an \(n\times n\) matrix. ◻

Contrast Proposition 9.4: in \(S_X\) the placement can carry almost all of the information, whereas in \(\mathrm{GL}(n,2)\) it carries at most \(n^2\) bits. A linear symmetry hypothesis is essentially an abstract group with a module, and it cannot hide arbitrary information in its placement. Figure 7 shows the closed types for \(n=3\).

9.3 What the maximal gap theorem means for search

The coordinates make the search for symmetric models concrete. A hypothesis is a type \((H,b)\) together with a placement, and one moves through the space by relabelling, by restriction with its Mackey splitting of cells, and by meets with other cheap hypotheses. It is natural to try to find good models of a given string \(x\) this way, by exhaustive, heuristic or learned search. Theorem 8.2 sets the limits of any such procedure.

Failure can be forced by the class, not the search.

For the strings of Theorem 8.2, no cell of a linear-symmetric partition costing much less than \(C(x)\) is a good model. No search strategy over \(\mathrm{Par}_{\mathrm{GL}}\), however it navigates the coordinates, can find one, because none exists. Conversely, a model found by search only gives an upper bound on \(h^{\mathrm{GL}}_x\). Since structure functions are not computable, no search yields matching lower bounds.

Failure says little about \(x\).

The strings of Theorem 8.2 are stochastic and normal. Their sufficient statistics are simple, and even computable from \(x\) by a short total program (Corollary 8.3). So “no good symmetric model found” means “no linear-symmetric structure found”. It is no evidence that \(x\) is random, nor that \(x\) is strange.

Permutation-group coordinates are complete but uninformative.

For the ambient group \(S_X\), search is complete in principle: by Theorem 5.1, every Kolmogorov model is a cell of a symmetric partition. But by Proposition 9.4, the canonical certificates are Young subgroups whose type is just a list of cell sizes, so for models of complexity much larger than \(2^{n/2}\) the search takes place almost entirely among placements, under every realisation. The homogeneous spaces \(S_X/N_{S_X}(U_b)\) can have size close to \((2^n)!\), and searching them is searching arbitrary finite sets under another name. The group structure helps only for models whose information lies mainly in the type.

Matrix-group coordinates are searchable but blind.

For \(\mathrm{GL}(n,2)\), the placement costs at most \(n^2\) bits (Proposition 9.6). The effective search space is therefore the discrete set of types, small abstract groups with faithful modules, times at most \(2^{n^2}\) placements: altogether \(2^{\mathrm{poly}(n)}\) hypotheses. This finiteness is what makes the search feasible, and it is exactly what the proof of Theorem 8.2 exploits: any family of \(2^{\mathrm{poly}(n)}\) decidable cells is blind to some stochastic normal strings. The same holds for \(\mathrm{AGL}(n,2)\), for coordinate permutations, and for any finite combination of such classes (the remark after Corollary 8.3). In short:

A coordinate system in which the space of symmetry hypotheses is small enough to search is small enough to miss simple structure.

Completeness requires the full group \(S_X\), where the hypotheses stop being meaningfully symmetric.

What search is good for.

None of this makes symmetric search useless. Theorem 8.2 is non-constructive. It shows that blind strings exist, not how often they occur in data of interest, and if such data tend to have symmetric regularities, the search target exists (Corollary 8.1) and finding it is a genuine discovery. The theorem changes what a search should report. It should not report “the structure of \(x\)”. It should report how much of the structure of \(x\) is symmetric: the best model found, with its deficiency \(C(p,B)+\log|B|-C(x)\), where \(C(x)\) is estimated by a compressor. A deficiency near the ceiling of Theorem 7.1 means that \(x\) looks random to linear symmetry. Four practical consequences follow.

  1. Pair symmetric search with strong-model search. Blind strings can be normal, so a search over all simple partitions can succeed where the symmetric search fails. The difference between the two results estimates \(\mathrm{soph}^{\mathrm{GL}}(x)-\mathrm{soph}(x)\).

  2. Search types first. For \(\mathrm{GL}(n,2)\), enumerate small types \((H,b)\) and only then optimise placements within each type.

  3. Refine by restriction and meets. Mackey splitting and meets are the natural moves for halving the cell of \(x\) (Question 7.2).

  4. Treat stalls as possibly genuine. If \(h^{\mathrm{GL}}_x\) violates the halving law, a search that stalls at some cell size may have reached a real plateau of \(h^{\mathrm{GL}}_x\), not a local optimum of the algorithm.

Strangeness is rare, since strange strings are non-stochastic and non-stochastic strings have small a priori probability [12]. Blindness to symmetry is plausibly common among stochastic strings, because a symmetric family has only \(2^{\mathrm{poly}(n)}\) cells. So in practice the gap between symmetric and arbitrary models, not the gap between strong and arbitrary ones, is the dominant limitation.

10 Open problems

  1. Halving as refinement. Resolve Question 7.2: does \(\mathrm{Par}_{\mathrm{GL}}\) admit cheap refinements of every cell, for instance by meets with cheap hypotheses, or by restriction moves whose Mackey decomposition halves the cell of \(x\) (Section 9)?

  2. Navigation. Use the coordinates \((b,\sigma)\) and the moves of restriction and relabelling to search the space of symmetric partitions for good models of a given string. Which moves are cheap, and how does the structure function change along them? Later papers in the series take this up with reinforcement learning (Section 1.4).

  3. Rigidity.

    Question 10.1. Is there a string \(x\) for which \(h^{\mathrm{GL}}_x\) and \(h^{\mathrm{str}}_{x,\varepsilon}\) are both small at some level, yet \(h^{\mathrm{GL}}_{x,\varepsilon}\) is large there? Such an \(x\) would have a good linearly homogeneous model and a good strong model, but no cheap symmetric partition, a separation caused by the rigidity of \(\mathrm{Par}_{\mathrm{GL}}\) rather than by computability.

    A related question comes from the remark after Corollary 4.3: is the canonical hypothesis \(p_B\) of a homogeneous set \(B\) always within \(O(\log n)\) bits of the cheapest symmetric partition having \(B\) as a cell?

  4. Type-dominated explanations. Charge the type and the placement separately, and define structure functions in which the placement cost is bounded. Which strings have sufficient symmetric explanations whose information lies mainly in the type? For \(\mathrm{Sym}\), Proposition 9.4 shows that arbitrary models need placement. For \(\mathrm{GL}(n,2)\), how do the at most \(n^2\) bits of placement trade against the type in optimal models?

  5. Counting symmetric partitions. Bound the number of \(p\in\mathrm{Par}_{\mathrm{GL}}\) with \(C(p)\le\varepsilon\) and given cell sizes, using types (Burnside and Green rings) and placements, and count the homogeneous sets \(\mathcal{A}_{\mathrm{GL}}\) by size. This would sharpen Theorem 8.2, whose counting ranges over all subgroups.

  6. Realizability. Which pairs \((h_x,h^{\mathrm{GL}}_x)\) occur? Conjecture: every pair \((P,Q)\) with \(P\) admissible, \(Q\) non-increasing, \(P\le Q\le n-\alpha\) and \(Q\) vanishing where \(P\) does, up to \(o(n)\); in particular every value of \(\mathrm{soph}^{\mathrm{GL}}(x)\) between \(\mathrm{soph}(x)\) and \(C(x)\).

  7. Explicit extremal strings. Find explicit stochastic strings with \(\mathrm{soph}^{\mathrm{GL}}(x)\approx C(x)\). Candidates are \((y,f(y))\) for simple \(f\) whose graph has neither large Walsh coefficients nor large linear symmetry groups.

  8. Canonicity and heredity. Is a sufficient cell of a cheap symmetric partition canonical, in the sense of Vereshchagin’s theorem for strong minimal sufficient statistics [11]? Is the code of an optimal symmetric model of a string with \(h^{\mathrm{GL}}_x\approx h_x\) again of this kind, as for normal strings [7]?

  9. Other ambient groups. Develop the lattices \(\mathrm{Par}_G\) for the affine group \(\mathrm{AGL}(n,2)\), for coordinate permutations \(S_n\), and for groups of polynomial automorphisms, and determine which regularities each sees.
